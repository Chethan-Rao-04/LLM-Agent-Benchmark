## Citation and Confidence Conventions

- `[FACT]` means the claim is directly observable in code, resources, or tests.
- `[INFERENCE]` means the claim is a reasoned interpretation where the source does not state the rationale.
- `UNCLEAR` marks behavior or intent that could not be verified from the current source.

## 1. Overview

- [FACT] The application is a non-web Spring Boot benchmark runner: `BenchmarkApplication` sets `WebApplicationType.NONE`, and `BenchmarkRunner` implements `ApplicationRunner`. See [BenchmarkApplication.java](../src/main/java/org/benchmark/app/BenchmarkApplication.java#L25) and [BenchmarkRunner.java](../src/main/java/org/benchmark/runner/BenchmarkRunner.java#L27).
- [FACT] A run generates benchmark cases, initializes a session with all tools exposed in that case, executes the case, records the case report, clears session state, and publishes summary artifacts. See [BenchmarkRunner.java](../src/main/java/org/benchmark/runner/BenchmarkRunner.java#L90), [BenchmarkRunner.java](../src/main/java/org/benchmark/runner/BenchmarkRunner.java#L101), [BenchmarkRunner.java](../src/main/java/org/benchmark/runner/BenchmarkRunner.java#L104), [BenchmarkRunner.java](../src/main/java/org/benchmark/runner/BenchmarkRunner.java#L106), [BenchmarkRunner.java](../src/main/java/org/benchmark/runner/BenchmarkRunner.java#L108), and [BenchmarkRunner.java](../src/main/java/org/benchmark/runner/BenchmarkRunner.java#L112).
- [FACT] The generator now uses a hidden process-family catalog rather than a single target-tool scenario catalog. `ToolCatalogLoader` parses families, tools, capabilities, workflows, and option profiles from `tool-catalog.yaml`. See [ToolCatalogLoader.java](../src/main/java/org/benchmark/gen/catalog/ToolCatalogLoader.java#L30), [ToolCatalogLoader.java](../src/main/java/org/benchmark/gen/catalog/ToolCatalogLoader.java#L41), [ToolCatalogLoader.java](../src/main/java/org/benchmark/gen/catalog/ToolCatalogLoader.java#L71), [ToolCatalogLoader.java](../src/main/java/org/benchmark/gen/catalog/ToolCatalogLoader.java#L87), [ToolCatalogLoader.java](../src/main/java/org/benchmark/gen/catalog/ToolCatalogLoader.java#L106), and [ToolCatalogLoader.java](../src/main/java/org/benchmark/gen/catalog/ToolCatalogLoader.java#L127).
- [FACT] One generated case can contain multiple target tools. The `BenchmarkCase` record carries `targetTools`, an ordered `targetPath` of `(toolName, commandName)` pairs, and `expectedStateByTool`. See [BenchmarkCaseGenerator.java](../src/main/java/org/benchmark/gen/BenchmarkCaseGenerator.java#L515), [BenchmarkCaseGenerator.java](../src/main/java/org/benchmark/gen/BenchmarkCaseGenerator.java#L519), [BenchmarkCaseGenerator.java](../src/main/java/org/benchmark/gen/BenchmarkCaseGenerator.java#L520), and [BenchmarkCaseGenerator.java](../src/main/java/org/benchmark/gen/BenchmarkCaseGenerator.java#L524).
- [FACT] The model-facing tool surface remains two Spring AI callbacks: `getCurrentState` and `executeCommand`. See [BenchmarkCaseToolCallbackFactory.java](../src/main/java/org/benchmark/tools/runtime/BenchmarkCaseToolCallbackFactory.java#L31), [BenchmarkCaseToolCallbackFactory.java](../src/main/java/org/benchmark/tools/runtime/BenchmarkCaseToolCallbackFactory.java#L39), and [BenchmarkCaseToolCallbackFactory.java](../src/main/java/org/benchmark/tools/runtime/BenchmarkCaseToolCallbackFactory.java#L49).
