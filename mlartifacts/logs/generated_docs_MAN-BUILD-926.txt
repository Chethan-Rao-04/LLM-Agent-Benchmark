# Tool Documentation: MAN-BUILD-926

Domain: MANUFACTURING
Description: Manages init configure execute operations.

Supported Commands:

## ini_sys
Description: Executes the ini_sys operation.
Preconditions:
- none
Options:
- `--quiet`: Suppress non-essential output.
- `--version`: Show version information and exit.
Effects:
- updates `system_status` with `ASSIGN` using `RUNNING`

## enb_pm
Description: Executes the enb_pm operation.
Preconditions:
- requires `system_status` to equal `RUNNING`
Options:
- `--force`: Force the operation even if warnings are present.
- `--interactive`: Prompt for confirmations interactively.
Effects:
- updates `precision_mode` with `ASSIGN` using `active`

## isp_cmp
