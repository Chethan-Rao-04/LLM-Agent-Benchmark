# Tool Documentation: MAN-CONTROLLER-213

Domain: MANUFACTURING
Description: Manages init configure execute operations.

Supported Commands:

## ini_sys
Description: Executes the ini_sys operation.
Preconditions:
- none
Options:
- none
Effects:
- updates `system_status` with `ASSIGN` using `RUNNING`

## enb_tp
Description: Executes the enb_tp operation.
Preconditions:
- requires `system_status` to equal `RUNNING`
Options:
- `--confirm`: Require explicit confirmation before proceeding.
Effects:
- updates `thermal_protection` with `ASSIGN` using `active`
