# Tool Documentation: MAN-PROCESS-900

Domain: MANUFACTURING
Description: Manages init configure execute operations.

Supported Commands:

## ini_sys
Description: Executes the ini_sys operation.
Preconditions:
- none
Options:
- `--help`: Show help information and exit.
- `--debug`: Enable debug output.
Effects:
- updates `system_status` with `ASSIGN` using `RUNNING`

## enb_pm
Description: Executes the enb_pm operation.
Preconditions:
- requires `system_status` to equal `RUNNING`
Options:
- `--confirm`: Require explicit confirmation before proceeding.
- `--verbose`: Enable verbose logging/output.
Effects:
- updates `precision_mode` with `ASSIGN` using `active`

## cal_cmp
Description: Executes the cal_cmp operation.
Preconditions:
- requires `system_status` to equal `RUNNING`
- requires `precision_mode` to equal `active`

- `--simulate`: Run in simulation mode.

Effects:
- no state change documented
