# Tool Documentation: MAN-SENSOR-679

Domain: MANUFACTURING
Description: Manages init configure execute operations.

Supported Commands:

## ini_sys
Description: Executes the ini_sys operation.
Preconditions:
- none
Options:
- `--timeout`: Set a timeout for the operation.
Effects:
- updates `system_status` with `ASSIGN` using `RUNNING`

## enb_si
Description: Executes the enb_si operation.
Preconditions:
- requires `system_status` to equal `RUNNING`
Options:
- `--interactive`: Prompt for confirmations interactively.
Effects:
- updates `safety_interlock` with `ASSIGN` using `active`

## cal_cmp
Description: Executes the cal_cmp operation.
Preconditions:
- requires `safety_interlock` to equal `active`
- requires `system_status` to equal `RUNNING`
Options:
- `--confirm`: Require explicit confirmation before proceeding.
Effects:
- no state change documented
