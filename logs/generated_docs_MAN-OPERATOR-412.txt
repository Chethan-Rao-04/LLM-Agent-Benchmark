# Tool Documentation: MAN-OPERATOR-412

Domain: MANUFACTURING
Description: Manages init configure execute operations.

Supported Commands:

## ini_sys
Description: Executes the ini_sys operation.
Preconditions:
- none
Options:
- `--timeout`: Set a timeout for the operation.
Effects:
- updates `system_status` with `ASSIGN` using `RUNNING`

## enb_tp
Description: Executes the enb_tp operation.
Preconditions:
- requires `system_status` to equal `RUNNING`
Options:
- `--force`: Force the operation even if warnings are present.
Effects:
- updates `thermal_protection` with `ASSIGN` using `active`

## msr_trb
Description: Executes the msr_trb operation.
Preconditions:
- requires `thermal_protection` to equal `active`
- requires `system_status` to equal `RUNNING`
Options:
- `--output`: Write output to a file.
- `--simulate`: Run in simulation mode.
Effects:
- no state change documented
