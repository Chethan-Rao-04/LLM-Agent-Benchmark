# Tool Documentation: MAN-GENERATOR-729

Domain: MANUFACTURING
Description: Manages init configure execute operations.

Supported Commands:

## ini_sys
Description: Executes the ini_sys operation.
Preconditions:
- none
Options:
- `--debug`: Enable debug output.
Effects:
- updates `system_status` with `ASSIGN` using `RUNNING`

## enb_si
Description: Executes the enb_si operation.
Preconditions:
- requires `system_status` to equal `RUNNING`
Options:
- `--version`: Show version information and exit.
Effects:
- updates `safety_interlock` with `ASSIGN` using `active`

## msr_trb
Description: Executes the msr_trb operation.
